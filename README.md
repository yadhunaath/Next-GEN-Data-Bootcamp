# Next-GEN-Data-Bootcamp
Project work of the summer internship class

This project, **Demand Forecasting System for Bike-Sharing Services**, uses the Seoul Bike Sharing dataset to analyze and predict hourly bike rental demand based on weather and time-related factors. The workflow includes data cleaning, date conversion, feature engineering, exploratory data analysis, and machine learning model development using Python and Scikit-learn. Important features such as **Hour, Temperature, Humidity, Wind Speed, Season, Holiday, Weekend, and PeakHour** were used to understand how demand changes across different conditions. The project evaluates model performance using **MAE, RMSE, and R²**, and the insights are presented through visualizations and an interactive **Power BI dashboard** to support better bike allocation, inventory planning, and scheduling decisions.

This repo contains all the required files such as Dataset(CSV) and the source code along with the PowerBI report that is reqiured for this project.
Save all these files in a single folder and run the Python code for unintereppted and error-free results
